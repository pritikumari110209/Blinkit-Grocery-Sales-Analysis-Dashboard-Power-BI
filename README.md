# Blinkit Grocery Sales Analysis Dashboard | Power BI

**By Priti Kumari**

## 📊 Project Overview

This project presents an interactive **Blinkit Grocery Sales Dashboard** developed using Microsoft Power BI.

The dashboard provides a comprehensive view of grocery sales performance and helps analyze important business dimensions such as outlet type, outlet size, outlet location, item type and outlet establishment year.

## 🎯 Project Objective

The main objective of this project is to transform grocery sales data into an interactive business intelligence dashboard that can be used for:

- Sales performance analysis
- Outlet performance comparison
- Product/category analysis
- Customer rating analysis
- KPI monitoring
- Business decision support

## 📈 Key KPIs

The dashboard includes the following major KPIs:

- Total Sales
- Average Sales
- Number of Items
- Average Rating

## 🔍 Dashboard Analysis

The dashboard provides analysis across:

- Outlet Establishment Year
- Outlet Type
- Outlet Size
- Outlet Location Type
- Item Type
- Item Fat Content
- Average Rating

## 📊 Visualizations

The Power BI dashboard contains:

- KPI Cards
- Sales Trend Analysis
- Bar Charts
- Donut Charts
- Funnel Chart
- Summary Table
- Interactive Slicers
